# FENGON PARTS — Telegram bot (Fengon S508)

Фақат Fengon S508 учун мўлжалланган Telegram дўкон боти.

## Функциялар
- Категориялар бўйича ягона каталог
- Маҳсулот номи бўйича қидириш (OEM қидируви йўқ)
- Маҳсулот расми, нархи ва тавсифи
- Буюртмада исм-фамилия, тўлиқ яшаш манзили ва телефон рақами мажбурий
- Телефонни Telegram contact тугмаси орқали юбориш ёки қўлда киритиш
- Маълумотларни тасдиқлашдан кейин буюртма сақланади
- Администраторга буюртма маълумотлари автоматик боради
- Администратор маҳсулот қўшади, буюртмаларни кўради ва ҳолатни ўзгартиради
- Буюртма ҳолати ўзгарса, харидорга хабар боради
- Каналга пост, мижозларга хабар ва статистика

## Ўрнатиш
Python 3.10+ керак.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

`.env` файлига BotFather токени ва администраторларнинг Telegram рақамли ID'ларини киритинг:
- `BOT_TOKEN`
- `ADMIN_IDS` — бир ёки бир нечта рақамли ID, вергул билан
- `CHANNEL_ID` — масалан `@fengon_zapchast`

Токенни ҳеч кимга юборманг ва очиқ гуруҳга жойламанг.

## Ишга тушириш
```bash
python run.py
```

Ботда `/start`, администратор аккаунтидан `/admin` юборинг.

## Маҳсулот қўшиш
`/admin` → `Маҳсулот қўшиш` → ном → категория → нарх → тавсиф → расм.

## Эслатмалар
- База SQLite: `data/fengon_parts.sqlite3`.
- Бот буюртмани қабул қилади, тўлов интеграцияси ҳозирча йўқ.
- Бот мижозга шахсий хабар юбориши учун мижоз аввал ботни очиб `/start` босган бўлиши керак.
- Ишга туширишдан олдин сервер, доимий ишлаш, захира нусха ва мониторинг созланиши керак.
